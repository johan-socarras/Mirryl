Mirryl incorporates software written by third parties. This document
identifies those components and reproduces the notices and licenses
their authors require to be kept.

It covers the Windows package:

    Mirryl.exe                  desktop application
    engine\mirryl-engine.exe    the "Mirryl Connect" mirroring engine
    platform-tools\             Android Debug Bridge and its libraries
    WebView2Loader.dll          Microsoft WebView2 loader
    phone-app\Mirryl.apk        Mirryl companion Android application

The companion Android application travels inside this package and is
installed on the phone by Mirryl itself, at the user's request - see
Section 5.

Components are incorporated in two different ways, and the difference

  (a) STATICALLY LINKED - compiled directly into Mirryl.exe and into

Software used only to BUILD Mirryl - procedural macros, code
generators and their own dependencies - is not covered here and is not
listed in the inventory. That code runs on the build machine and no
part of it is delivered to users.

Mirryl has not modified the source code of any third-party component.

2.7 CODE DEVELOPED FROM ANDROID OPEN SOURCE PROJECT SOURCES
--------------------------------------------------------------------

Mirryl implements the Android wireless-debugging pairing protocol
("adb-tls-pairing") directly, so that the PC can act as the pairing
server. The adb command-line tool described in Section 1 does not
implement that side of the protocol: it implements the six-digit-code
client side, which Mirryl uses through adb itself.

This implementation is Mirryl own code, written in Rust. It was
developed by studying the publicly published Android Open Source
Project adb sources, which are licensed under the Apache License,
Version 2.0, and it uses the SPAKE2 generator constants M and N as
published in BoringSSL, which the protocol requires in order to
interoperate with the device.

Copyright (C) The Android Open Source Project.
Licensed under the Apache License, Version 2.0 - full text in Section
8.1.

https://android.googlesource.com/platform/packages/modules/adb/

7. VIDEO CODECS (H.264 / AVC)
==============================================================================

Mirryl mirroring pipeline transmits and displays video encoded in the
H.264 (AVC) format. Neither the desktop application, the mirroring
engine, nor the Android agent implements an H.264 encoder or decoder
of its own:

  - On the Android device, video is encoded through the platform own
    MediaCodec API, backed by whichever encoder the device
    manufacturer ships with the Android operating system.

  - On the Windows PC, video is decoded through the WebCodecs
    VideoDecoder API provided by the Microsoft Edge WebView2 runtime.

In both cases Mirryl calls a codec that the underlying platform
already provides through a public, documented interface. Mirryl does
not implement, embed, distribute or modify any AVC/H.264 codec
implementation.
